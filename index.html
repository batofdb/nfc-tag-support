NFC Tag Bench

Read, write, copy, and program NFC tags from your iPhone.

Thanks for using the app. If something isn't working the way you expect, this page covers the questions that come up most, and there's a link at the bottom for anything it doesn't answer.

What the app does

  • Read - tap a tag and see what's on it: tag type, chip, serial, memory, and any records it's carrying.
  • Write - put a URL, some text, or a plain record onto a tag.
  • Copy - read one tag, write what it holds onto another.
  • Format and Erase - prepare a blank tag, or clear one you've already used.
  • Advanced - send raw hex commands and see exactly what the tag sends back.
  • Batch - write the same thing to a stack of tags, one after another, checking each one afterward.
  • Library and Copyboard - keep what you've read so you can write it again later, without needing the original tag.
  • Recipes - chain steps like read, verify, write, and save into one job you can run again, or share as a file. A shared recipe shows every step, and every raw command byte in it, before anyone adds it.

Things that aren't the app's fault

A few limits come from the iPhone itself, and no app can work around them. It's worth knowing which is which so you're not troubleshooting something that can't be fixed.

  • MIFARE Classic tags don't work on iPhone. Not in this app, not in any app. iOS doesn't support the protocol. A lot of cheap tags sold online are Classic, so if a tag simply won't read, that's the first thing to check. The app tells you when it spots one.
  • The scan sheet is Apple's, not ours. When you start a scan, iOS takes over the screen. We can't restyle it, move it, or keep it open longer than about 60 seconds.
  • Every tag needs its own scan. That's why writing a stack means the sheet appears once per tag. Batch mode keeps count for you and puts your progress in the sheet's own text, which is the one part we control.
  • iPhone only. iPad and Mac don't have the NFC hardware for this.

Common problems

The tag won't read at all. Hold the top edge of the phone flat against the tag and keep it still - the antenna is near the top, not the middle. If it still won't read, it may be MIFARE Classic. Try Read and see what the app reports.

A write failed partway. Nothing was changed unless the app says otherwise. Read the tag again and the app will tell you exactly what's on it now.

The tag is full. Different chips hold different amounts - some as little as 48 bytes. The app shows you the capacity before you write, so if your content doesn't fit, you'll see it before you tap.

A raw command is flagged as permanent. Some commands can't be undone. Writing to the low pages or the configuration pages can lock a tag for good, with no way back for anyone. The app blocks those by default and asks you to confirm, naming the exact command. If you know what you're doing, you can go ahead. If you're pasting a command you found online, read the warning first.
